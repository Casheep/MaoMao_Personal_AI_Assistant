# MaoMao Personal AI Assistant

猫猫是一个更像人的 Windows AI 助手：通用模型负责理解和思考，小技能负责执行具体动作，互动感是第一追求。

当前仓库处于 `beta` 阶段，默认采用 API 文本、转写和语音生成；记忆、权限、操作记录和个人配置保存在用户自己的电脑上。

当前版本：`v0.0.3_beta3`

## 特点

- Kimi 优先的文本模型路由，支持 MiMo API 回退。
- MiMo API 语音转写与流式语音生成。
- Vosk 本地候选监听与 Sherpa-ONNX 二级唤醒检查，不占用显存。
- SQLite 本地记忆、权限、费用和任务记录。
- 可开关的小技能：浏览器、应用、屏幕、音量、定时任务和智能设备等。
- 用户路径、设备信息和令牌均在首次使用时于本机生成。

## 运行

需要 Windows 10/11 与 Python 3.12（兼容 Python 3.13）。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-release.txt
.\.venv\Scripts\python.exe -m assistant_app.qt_quick.app
```

首次使用时可从界面填写 API 密钥，并按需配置唤醒词、技能权限和设备集成。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

## Beta 更新

### v0.0.3_beta3

- 将唤醒流程拆分为候选检测、已有本地声纹校验和独立二级关键词检查；二级检查采用 CPU/INT8 Sherpa-ONNX 中文模型，音频仅在内存中处理，不写入诊断日志或上传。
- 二级检查默认以 `shadow` 模式运行：记录不含语音内容的耗时和通过结果，但暂不否决正常唤醒，便于先用真实环境数据验证漏唤醒风险后再切换到强制模式。
- 默认要求连续两次完整 partial 命中，并关闭“猫”单字触发“猫猫”，减少相近语音和短片段误触；完整唤醒词、现有声纹边界与 Qt Quick 交互保持不变。
- Lite 版可按需下载经过 SHA-256 校验的二级检查模型，并只提取运行所需的 5 个数据文件；Full 版构建时验证并打包同一模型。
- 语音交互遵循“说出的内容进入记录”：识别到的用户语音、本地唤醒回应、模型回答以及“拜拜”“没事了”后的本地告别回复都会正常显示并保存；本地回应仍不调用模型。
- 每次启动都从收起的技能栏、收藏夹和创建工具栏开始；对话记录中的“你”使用收藏夹棕橙色，“猫猫”继续使用蓝色，便于快速区分双方。
- 连续语音录制在自适应音量门控之外增加本地频谱人声检查，过滤持续底噪、宽带白噪声和单频嗡声，减少噪声触发无效转写；分析仅在内存中完成。

### v0.0.3_beta2

- 为明确的点击和文字输入指令增加 Windows UI Automation 快速通道：仅在前台窗口存在唯一精确匹配的可操作控件时本地执行，不再等待截图和云端视觉识别。
- 在需要模型判断的屏幕任务中，优先提供经过压缩和排序的 UIA 控件名称、类型和必要坐标，并把视觉概览直接附在第一次模型请求中，避免“先询问模型、再截图、再询问视觉模型”的额外往返。
- UIA 点击和输入继续沿用现有应用与窗口确认、技能开关和操作记录边界；输入框当前内容不会进入预读取上下文，界面文字按不可信数据处理。
- 将屏幕性能诊断细分为 UIA 快照、匹配、执行、截图、图片保存和编码耗时；回答记录同时显示各模型与工具的分阶段耗时，便于区分本地处理与云端模型延迟。
- 截图优先只取当前前台窗口，并按任务自动选择 896 像素概览、1152 像素均衡或 1536 像素精细 JPEG；普通屏幕观察使用一次 K2.6 非思考视觉调用，小字、OCR、图表和精确视觉任务才使用 K3 精细档。
- 当概览无法看清目标时，模型可以只放大一个相关区域继续识别；不会预先把整屏切成多张图，也不会在简单任务中重复发送全屏，从而兼顾视觉 token、上传体积与小目标精度。
- 将自适应截图、局部放大和任务级原图生命周期集中到独立屏幕会话模块，避免保留 4K 原图时的额外内存复制，并在任务清理时主动释放。
- 为首次打开音频输出流增加 800 毫秒静音预热，避免会休眠的音箱吞掉句首；输出流保持活跃后恢复原有 220 毫秒句前留白。
- 在收藏夹中的“定时任务”技能设置里提供任务列表，可查看状态、停用或删除任务；猫猫未运行期间错过的任务会被标记为“已错过”，一次性任务不再执行，每日任务直接顺延到下一次。
- 在每条回答的记录信息中显示本次模型与工具处理的总耗时；定时任务列表同时显示上次结果及运行耗时。
- 对话记录中的“你”和“猫猫”统一使用蓝色发送者标识，系统记录继续使用次要文字色。
- 移除已无实际用途的语音播放暂停、继续和停止按钮；等待后续语音自然超时时安静回到就绪状态，不再显示“语音转写失败”，说“没事了”等结束语会退出连续对话并恢复唤醒词等待。

### v0.0.3_beta1

- 在中央对话列加入可展开的紫色工具栏标签，并重新协调工具栏、消息输入区、历史记录区、音频控制与左右侧栏在常规和紧凑窗口中的布局。
- 新增由 Kimi K3 独立驱动的“组合技能”和“代码技能”生成器：前者把猫猫已有工具编排为新能力，后者通过官方 Kimi Agent SDK harness 创建 Python 技能。
- 为代码生成 Harness 加入任务专属临时工作区、限界文件工具、受控 Shell、依赖下载、程序校验和最多三轮自动修正，同时保持子 Agent 关闭。
- 将生成技能完整接入现有技能系统，支持本地保存、自动发现、触发匹配、分类、启用或停用、收藏和删除，不新增与技能重叠的第三种能力类型。
- 为组合技能增加工具白名单校验，并为代码技能增加权限声明、静态代码检查、内容哈希校验和限时子进程执行，降低生成内容越权或被篡改的风险。
- 修正唤醒词触发时恢复并聚焦最小化窗口的问题，使语音交互可以继续在后台进行。
- 将运行环境升级到 Python 3.12/3.13，便携包加入 Kimi Agent SDK，并加强启动器缓存版本校验，避免旧版可执行文件进入新包。
